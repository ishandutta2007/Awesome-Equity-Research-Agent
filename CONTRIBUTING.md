# Contributing to Awesome Equity Research Agents

Thank you for your interest in contributing to the **Awesome Equity Research Agents** repository! We are building the definitive curated list of **Autonomous AI Agents** and **Agentic Workflows** for the financial sector.

## How to Contribute

We welcome contributions that focus on **Agentic capabilities** (multi-step reasoning, autonomous tool-use, multi-agent collaboration) in equity research and market intelligence.

### Adding a Project or Product

1. **Fork the Repository**: Create your own fork of the repo.
2. **Choose the Right Section**:
   - **SaaS Products**: For commercial platforms and enterprise tools.
   - **Open-Source GitHub Projects**: For codebases, frameworks, and local LLM setups.
   - **Agentic Frameworks**: For the underlying tech stacks (LangGraph, CrewAI, etc.).
3. **Format Your Entry**:
   - Use the format: ` - **[Name](Link)**: Brief description (1-2 sentences) focusing on the **Agentic** or **Autonomous** value proposition.`
   - Example: `- **[FinRobot](https://github.com/ai4finance-foundation/FinRobot)**: Open-source AI agent platform for financial applications, including specialized agents for fundamental analysis and report generation.`
4. **Submit a Pull Request**: Provide a clear description of why the project belongs here.

### Contribution Guidelines

- **Focus on Agents**: We prefer projects that demonstrate multi-step reasoning over simple chatbots.
- **Factuality**: Ensure links are active and descriptions are accurate.
- **Citations**: If the tool has benchmark results (e.g., accuracy on financial datasets), please include them.

## Niche Keywords for Contributions

When writing descriptions, consider using these targeted terms to help discovery:
- **Agentic RAG**
- **Autonomous Financial Modeling**
- **SEC Filing Analysis Agents**
- **Multi-Agent Investment Orchestration**
- **Verifiable Financial Intelligence**
